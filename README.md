# Romain Faure, Photo and Video Work

Portfolio of Romain Faure, photographer and videographer in Amsterdam: client reels, poster shoots for The JR Scheme, stand-up comedy films, live photography and projects for Rostra Economica and OnTap Visual Agency.

The site is a single static page (`index.html`) with its images and video loops in `img/`. It is served with GitHub Pages straight from the `main` branch; there is no build step.
